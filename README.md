# Formularios 9S Gestión Empresarial

Formularios digitales de los sistemas de gestión de los clientes de 9S.

## Estructura

Cada empresa tiene su carpeta y cada formulario su subcarpeta con el código del documento:

```
/                         página de inicio (sin listado de empresas)
/clarisa/sst-fr-41/       Clarisa Cloud · SST-FR-41 Inspección y evaluación de puesto de trabajo
```

Enlace de cada formulario: `https://gestorempresarial9s-prog.github.io/formularios-9s/<empresa>/<codigo>/`

## Cómo funcionan

- Se abren en cualquier navegador, sin cuenta.
- No guardan datos en ningún servidor: al terminar generan un PDF que el trabajador envía por WhatsApp.
